About this test

This benchmark asks LLMs the SapplyValues political questionnaire in a controlled, direct prompt format. Each answer is normalized to the questionnaire's agree/disagree scale, then converted into three axes: economic left/right, liberty/authority, and progressive/conservative.

These charts show how each model answered under this exact setup; they should not be read as a model's fixed “beliefs”. Prompt wording, model safety behavior, neutrality preferences, and reasoning settings can all change the results.
